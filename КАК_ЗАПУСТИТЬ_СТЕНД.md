# Как самому запустить стенд Practice-15

Стенд: GNS3 `10.31.2.8`, проект **1**. Все команды выполняются в консолях ВМ
(в GNS3: правой кнопкой по ВМ → **Console**, либо ссылка `telnet://10.31.2.8:порт`
в панели Map topology).

Вход в Linux-ВМ: логин `student`, пароль `student`, затем `sudo -i` (пароль `student`).
Вход в WIN-01: `Administrator` / `student`.

---

## Шаг 1. Запустить проект в GNS3

1. Открой http://10.31.2.8:3080/static/web-ui/bundled
2. Логин: `admin`, пароль `M6WFYxuaiembEL`.
3. Открой проект **1**.
4. Нажми **▶ (Start all)** — запустятся все ВМ.
5. Подожди 1–2 минуты (RED OS грузится ~1 минуту).

Проверка: в панели Map topology у всех узлов зелёные индикаторы.

---

## Шаг 2. CTRL-01 — приёмник показаний

В консоли CTRL-01:

```bash
sudo -i
systemctl start docker
cd /root/practice4/ctrl
docker compose -f compose.yml up -d
docker compose -f compose.yml ps
curl -s http://127.0.0.1:8080/health
```

Ожидаемо: контейнер `ctrl-receiver-1` — **Up**, ответ `{"status":"ok","version":3,...}`.

## Шаг 3. IOT-01 — Node-RED

В консоли IOT-01:

```bash
sudo -i
systemctl start docker
cd /root/practice4/iot
docker compose -f compose.yml up -d
docker ps
```

Ожидаемо: контейнер `node-red` — **Up (healthy)**.

Поток уже сохранён внутри Node-RED. Если каким-то образом пропал — импортируй
`flow-fan-mon.json` из репозитория: меню ☰ → Import → Clipboard → вставить → Import → **Deploy**.

## Шаг 4. DB-01 — база и история

В консоли DB-01:

## Шаг 5. MON-01 — Prometheus и Grafana

В консоли MON-01:

```bash
sudo -i
systemctl start prometheus
systemctl start grafana-server
systemctl is-active prometheus grafana-server
curl -s http://127.0.0.1:9090/-/ready
```

Ожидаемо: обе службы **active**, ответ `Prometheus Server is Ready.`

## Если нет интернета в ВМ (не открываются сайты, не качается docker)

На RTR (консоль):

```bash
sudo -i
sysctl -w net.ipv4.ip_forward=1
iptables -t nat -C POSTROUTING -o enp2s0 -j MASQUERADE 2>/dev/null || \
  iptables -t nat -A POSTROUTING -o enp2s0 -j MASQUERADE
```

Проверка с CTRL-01: `ping -c 2 8.8.8.8`.

---

## Если что-то не так

| Симптом | Что проверить |
|---------|---------------|
| `docker: command not found` | `systemctl start docker` |
| Контейнер не поднялся | `docker compose -f compose.yml logs --tail=50` в папке сервиса |
| История пустая / висит | `docker restart practice6-storage-1`, затем обновить страницу |
| Цель в Prometheus DOWN | `curl http://127.0.0.1:8080/health` на CTRL-01, проверить контейнер приёмника |
| Нет данных в Grafana | проверить, что в Node-RED нажат **Deploy** и поток активен |
| Grafana не открывается | `systemctl restart grafana-server` на MON-01 |
